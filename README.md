# Detection & Prediction of Mental Health, Brain Stroke, and Diabetes

End-to-end ML project with 3 independent modules (mental health, stroke, diabetes)
sharing one pipeline pattern: Ingestion → Transformation → Training → Prediction → App.

## Setup
```bash
pip install -r requirements.txt
```

## 0. Quick start (everything already trained)
```bash
pip install -r requirements.txt
python app/app.py          # open http://127.0.0.1:5000
```
Trained models are in `models/`, metrics + charts in `results/`.

## 1. Add your datasets
Place raw CSVs here (names must match `src/components/data_ingestion.py`'s `MODULE_CONFIG`):
```
data/raw/mental_health/mental_health_raw.csv   (columns: text, label)
data/raw/stroke/stroke_raw.csv                 (standard Kaggle stroke schema)
data/raw/diabetes/diabetes_raw.csv             (Pima Indians Diabetes schema)
```
If your column names differ, update the config dicts at the top of:
- `src/components/data_ingestion.py`
- `src/components/data_transformation.py`

## 2. Train a module
```bash
python -m src.pipeline.train_pipeline --module diabetes     # start here
python -m src.pipeline.train_pipeline --module stroke
python -m src.pipeline.train_pipeline --module mental_health
python -m src.pipeline.train_pipeline --module all          # runs all 3 in order
```
This runs ingestion → transformation → trains all 6 models → saves the best one to
`models/<module>/best_model.pkl` and writes a comparison table to
`results/<module>/model_comparison.csv`.

## 3. Run the app
```bash
python app/app.py
```
Then open http://127.0.0.1:5000 in your browser. Routes: `/`, `/mental-health`, `/stroke`, `/diabetes`.

## Project structure
```
src/
  exception.py        custom exception with file+line info
  logger.py            timestamped logging setup
  utils.py             save/load objects, model evaluation helpers
  components/
    data_ingestion.py       reads raw CSV, stratified train/test split (all 3 modules)
    data_transformation.py  tabular preprocessing + text/TF-IDF preprocessing (all 3 modules)
    model_trainer.py        trains & compares the 6 models, saves best (all 3 modules)
  pipeline/
    train_pipeline.py       orchestrates ingestion->transformation->training
    predict_pipeline.py     loads saved models, exposes predict_*() for the app
app/
  app.py               Flask entrypoint, one route per module (GET form + POST predict)
  templates/           Jinja2 HTML templates (base.html + one per module)
  static/style.css     minimal styling
notebooks/             EDA notebooks (exploration only, not production code)
data/raw/, data/processed/, models/, results/   per-module subfolders
```

|---|---|---|---|---|---|---|
| Diabetes | REAL (Pima, 768 rows) | Random Forest | 0.844 | 0.778 | 0.778 | 0.942 |
| Stroke | SAMPLE (synthetic, 5110 rows, 4.2% positive) | SVM | 0.820 | 0.581 | 0.214 | 0.810 |
| Mental health | SAMPLE (synthetic text, 4 classes) | Logistic Regression | 0.966 | 0.966 | 0.966 | n/a |

Full per-model tables: `results/<module>/model_comparison.csv`; charts: `model_comparison.png`,

## IMPORTANT: datasets
Only the **diabetes** dataset was in the original upload. `stroke_raw.csv` and
`mental_health_raw.csv` were generated by `scripts/generate_sample_data.py` with the correct
schemas so the full pipeline runs. **They are synthetic, so their metrics are not real results.**
Before submitting, replace them with the real Kaggle files (same names/columns) and re-run:
```bash
python -m src.pipeline.train_pipeline --module all
```
Suggested sources: Kaggle "Stroke Prediction Dataset" (fedesoriano) and a Kaggle
"Sentiment Analysis for Mental Health" dataset (rename columns to `text`, `label`).

## What was added / fixed vs. the original scaffold
- `class_weight="balanced"` on LR / Tree / RF / SVM (stroke imbalance TODO)
- Model selection by 5-fold cross-validation on train data (no test-set leakage)
- `src/components/model_evaluation.py`: comparison, confusion-matrix and ROC charts
- Stroke result now shows true P(stroke); medical disclaimer in every page
- pandas-3 warning fixed in data_validation.py; `.gitignore`; sample-data script

## Notes
- Stroke recall matters more than accuracy (missing a stroke is costly); F1/recall/ROC-AUC are the right metrics.
- `clean_text()` is basic; upgrade with nltk/spacy lemmatization for real text data.
- `notebooks/MODEL_TRAINING_STROKE.ipynb` expects `stroke_cleaned.csv` and `xgboost`; adjust the path or install xgboost to run it.
